# 你一生的故事 / Story of Your Life

本地优先的互动记忆杂志 Demo，包含 Landing、公开虚构体验与私人工作台。

## 运行

```bash
python3 -m http.server 4173 -d dist
```

打开 `http://localhost:4173/`。页面为 `/`、`/demo/`、`/studio/`。

## 已实现

- 三层时间切片叙事、年龄切片、工作原理与隐私承诺。
- 18 / 22 / 26 岁虚构资料、本地模板回答和可展开的原始来源。
- 日记和多照片新增、日记编辑、单条删除、年月时间线、本地检索问答、记忆卡片、JSON 导出与清空。
- IndexedDB 本地持久化、响应式布局、键盘焦点与减少动态效果适配。

## 数据与隐私

资料保存在当前浏览器的 IndexedDB。图片读取为 Data URL，不会由本站主动上传。它不是加密云存储；清理浏览器数据会丢失资料，建议定期导出 JSON。公开 Demo 均为虚构，其中 2030 明确标为虚构未来。

## 结构

`dist/index.html`、`dist/demo/index.html`、`dist/studio/index.html` 是三个页面外壳；`dist/styles.css` 是视觉系统；`dist/app.js` 包含页面、交互、示例数据和本地存储。

## 已知限制

- 没有真实 AI：Demo 使用确定性模板，工作台使用本地关键词检索，界面均明确标注。
- 浏览器不能可靠读取所有照片 EXIF，因此要求用户确认日期；不会把上传日期冒充拍摄日期。
- 语音、视频、微信 Bot、账号与云同步未实现。
- 若接入真实模型，应新增服务端检索接口，只发送用户明确授权的片段并返回稳定来源 ID；API key 不得进入浏览器代码。
